# IMPERIA V44 - Rediseño visual profesional

## Objetivo
Elevar la apariencia gráfica de toda la plataforma para que se sienta como una aplicación profesional, con acabado tipo Figma/Lovable, manteniendo la lógica existente.

## Cambios aplicados
- Nueva capa visual global `v44-premium-redesign.css`.
- Mejoras en login, registro e ingreso como invitado.
- Hero principal con estilo institucional premium.
- Tarjetas de cursos, herramientas, perfil, certificados y premium con glassmorphism limpio.
- Mejor contraste en modo claro y oscuro.
- Botones, chips, badges, progress bars y navegación con acabado más profesional.
- En PC, el sistema deja de verse como una pantalla angosta y pasa a mostrarse como dashboard responsive.
- En móvil se mantiene apariencia tipo app nativa.
- Se conservan certificados, cursos, pagos simulados, navegación fija, modo invitado y modo oscuro.
