# Política de videos y atribución

IMPERIA Final Profesional usa videos externos únicamente como embeds de YouTube. No descarga, no copia y no redistribuye archivos de video.

## Reglas para uso responsable

1. Mantener visible el crédito del canal o autor.
2. Usar el reproductor embebido oficial.
3. No eliminar marcas del autor ni presentar el video como propio.
4. Confirmar que el video permita inserción.
5. Para uso comercial, obtener autorización expresa o usar contenido propio/licenciado.

## Videos incluidos como referencia

Los IDs incluidos en `js/data.js` son recursos de apoyo editables. Puedes reemplazarlos por videos propios o por videos con permisos documentados.

## Recomendación

Para una versión comercial, crea una carpeta de documentación con:

- URL del video.
- Autor/canal.
- Fecha de consulta.
- Tipo de permiso o licencia.
- Captura o evidencia de autorización, si corresponde.

## Nota sobre esta versión

Los videos siguen funcionando como contenido embebido externo. No se descargan ni se empaquetan como archivos propios. Para producción comercial se debe revisar cada licencia, permiso o autorización del autor/canal.
