# Roadmap para llevar IMPERIA a producto real

## Fase 1: Demo comercial

- Ajustar identidad visual final.
- Crear videos propios o licenciar contenido.
- Agregar más preguntas por clase.
- Agregar sonidos y animaciones de recompensa.
- Crear landing pública.

## Fase 2: MVP con backend

- Autenticación real.
- Base de datos de usuarios.
- Panel de administración de cursos.
- Recuperación de contraseña.
- Métricas de progreso.
- Certificados con validación pública.

## Fase 3: Monetización

- Pasarela de pago.
- Planes mensuales/anuales.
- Gestión de suscripciones.
- Facturación si aplica.
- Control real de anuncios.

## Fase 4: Escalamiento

- App móvil PWA avanzada o app nativa.
- Comunidad moderada.
- Ranking por cohortes.
- Mentor virtual con IA.
- Integraciones educativas y alianzas.
