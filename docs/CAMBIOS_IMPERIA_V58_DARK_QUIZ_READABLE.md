# IMPERIA v58 - Corrección de modo oscuro en quizzes

## Corrección principal
- Se solucionó el problema de opciones blancas con texto casi invisible en el quiz final.
- Se aplicaron estilos de alta prioridad para modo oscuro en:
  - quiz final tipo Duolingo;
  - quizzes dentro de lecciones;
  - minijuegos tipo quiz.

## Estados visuales
- Opción normal: fondo oscuro y texto claro.
- Opción hover: borde verde/azulado y texto blanco.
- Opción correcta: fondo verde oscuro y texto legible.
- Opción incorrecta: fondo rojo oscuro y texto legible.
- Feedback inferior: texto visible en modo oscuro.
