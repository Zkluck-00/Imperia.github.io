# IMPERIA V34 - Corrección modo oscuro y barra fija

## Cambios aplicados

### Modo oscuro
- Se corrigieron colores en tarjetas de herramientas, cursos, certificados y anuncios.
- Se aumentó el contraste de títulos, párrafos y textos secundarios.
- Los anuncios ya no quedan crema con texto poco visible en modo oscuro.
- Inputs, badges e íconos ahora tienen contraste adecuado.

### Barra de navegación
- La barra inferior queda fija y visible.
- Se agregó espacio inferior al contenido para que la barra no tape botones o tarjetas.
- Se mantuvo el desplazamiento horizontal de la barra.
- Se reforzó el z-index para que no desaparezca detrás del contenido.
