# CAMBIOS IMPERIA V8 - UI profesional

Versión enfocada en mejora visual UI/UX sin backend.

## Cambios aplicados

- Reemplazo visual de emojis por iconografía SVG profesional integrada en `app.js`.
- Nueva paleta fintech educativa: azul noche, verde financiero, celeste fintech, dorado premium y morado suscripción.
- Rediseño de botones, tarjetas, badges, nodos del mapa, tienda, planes, premium y login.
- Mejora de estados visuales: disponible, completado, bloqueado, premium y gratuito.
- Animaciones y microinteracciones más limpias.
- Se mantiene almacenamiento local con `localStorage`.
- No se agregó base de datos ni backend.

## Archivos principales modificados

- `js/app.js`
- `css/imperia-ui.css`
- `js/data.js`
