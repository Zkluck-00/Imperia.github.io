# IMPERIA V49 - IMPERIA PRO y cursos exclusivos

## Cambios aplicados
- La suscripción ahora se presenta como **IMPERIA PRO**.
- Precio actualizado a **S/ 34.99**.
- Beneficios actualizados: 500 coins para canjear por 5 % de descuento en un curso exclusivo, eliminación de anuncios y acceso a conferencias disponibles.
- Los cursos gratuitos ahora cuentan con **12 lecciones** y **5 monedas por lección**.
- Se agregaron 3 cursos exclusivos: Administración Financiera para PYMES, Administración y Contabilidad, y Gestión Comercial.
- Se dejaron materiales y enlaces como plantilla para completar luego con los archivos definitivos.
